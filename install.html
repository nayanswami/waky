Why this happens

The installer isn’t code-signed yet

Windows SmartScreen warns about every new app. The installer is per-user, so it never asks for administrator rights.

Check the file

Verify the download

In PowerShell, run Get-FileHash .\Waky-Setup.exe. The result should match the SHA-256 published with each release.

Verify your download →

Change your key

Update your Groq key

Settings → Privacy → API keys. Paste the new key into Groq API key and press Save. No reinstall needed.

Uninstall

Keeps your data

Uninstalling removes the app and its startup entry but keeps your settings, so a reinstall picks up where you left off.
