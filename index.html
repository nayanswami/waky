Good questions.

Windows says "Windows protected your PC".

The installer is not code-signed yet, so SmartScreen warns about new apps. Click More info, then Run anyway. The guide shows where.

Does it work in every app?

Waky pastes into whichever text field has focus: browsers, Gmail, WhatsApp Web, Notion, editors, chat apps. Elevated (administrator) windows can block pasting from normal apps.

How is this different from normal dictation?

Normal dictation types what you said. Waky understands what you meant and follows instructions you speak or define, so you get the finished email, list or post.

Do I need an account?

No. There is no Waky account. For cloud features you add your own Groq key. For local mode you need nothing.

What about Mac or Linux?

Windows only for now. Other platforms are on the roadmap.
