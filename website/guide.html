Setup guide

From download to your first dictation.

About two minutes. You need a Windows 11 PC, a microphone, and a free Groq account (or skip Groq and run fully offline).

1. Install

  1. Download Waky-Setup from the home page and run it.
  2. If Windows shows Windows protected your PC, click More info, then Run anyway. The installer is not code-signed yet, so SmartScreen warns about every new app.
  3. Finish the installer. Waky opens, adds an icon to the system tray, and starts the setup wizard.

The installer is per-user, so it does not ask for administrator rights.

Verify your download (optional)

Open PowerShell in your Downloads folder and run Get-FileHash .\Waky-Setup.exe. The result should match this SHA-256:

published with each release

2. Get a free Groq API key

Groq runs the speech recognition and the writing model. Waky never ships with a key, so you use your own.

  1. Open console.groq.com/keys and sign in. Google sign-in works.
  2. Click Create API Key and name it Waky.
  3. Copy the key. It starts with gsk_. Groq shows it only once.
  4. Paste it into the Waky wizard and press Verify key. A green check means it works.

Your key is saved in Windows Credential Manager on your PC and is sent only to Groq. Treat it like a password and never paste it into a screenshot or chat.

3. First-run setup

The wizard has a few short screens:

  1. Engine. Groq cloud (recommended) or local only.
  2. Key. Paste and verify your Groq key. Skipped for local only.
  3. Hotkey. Click the box and press the keys you want together. Use a modifier (Ctrl, Alt, Shift, Win) or a function key so normal typing never triggers it.
  4. Pill style. Pick the floating indicator you like. Change it later in Settings > General.
  5. Try it. Click the practice box, hold your hotkey, speak, release.
  6. Finish. Choose whether Waky starts with Windows.

4. Using Waky

Click into any text field, hold the hotkey, speak, and release. The text is pasted for you. Waky never presses Enter.

KeyWhat it does
Ctrl + Win (hold)Push-to-talk. Default, changeable in Settings > Hotkeys.
F8 (hold)Backup push-to-talk if another app uses Ctrl+Win.
F9Hands-free: press once to start, again to stop.
EscCancel the current recording or processing.

Rewrite selected text

Select text in any app, hold the hotkey, and say what you want: "make it shorter", "bullet points", "write email, professional tone". The selection is replaced with the result. With nothing selected, Waky just dictates.

The floating pill

Hover over the pill to reveal a gear that opens Settings. Hold Alt and drag to move it, and it remembers where you put it. If it ever goes missing, right-click the tray icon and choose Reset Floating Bar Position.

5. Custom modes

Open Settings > Commands.

  1. Under My standing instructions, write anything Waky should always know: who you are, your tone, how you sign emails.
  2. Click Add Command to create a mode.
  3. Set a Display name and one or more Trigger phrases, one per line, such as blog mode.
  4. Under Instruction for AI, describe in plain language what the mode should do.
  5. Optionally add an Output format to fix the layout, then press Save Command.

Now say the trigger phrase anywhere in a sentence. Waky removes the phrase, follows your instruction, and pastes the result. You can combine modes: "write email, professional tone, extend".

Custom modes and rewriting need the Groq key. Without it, Waky falls back to simple built-in cleanup.

6. Offline fallback

If Groq's free usage limit is reached, Waky can switch to a Whisper model on your PC and switch back when the limit resets. To prepare for that, open Settings > Transcription, pick a local model, and press Download local model.

Troubleshooting

"Groq rejected the request" or HTTP 401 / 403

The key is wrong or revoked. Create a new one at console.groq.com/keys and paste it in Settings, or rerun the wizard.

Nothing happens when I hold the hotkey

Another app may own Ctrl+Win. Try F8, or pick a different combination in Settings > Hotkeys. Check the tray menu that Waky is not paused.

The text is not pasted

Click into the text field first. Windows blocks pasting into apps running as administrator from a normal app, so run the target app normally.

"Groq limit reached" and no local model

Download a model in Settings > Transcription, as described above.

Wrong microphone

Choose it in Settings > Audio and run the quick mic test.

Still stuck? Errors are logged to %APPDATA%\Waky\logs\error.log. API keys are never written there.

Your data

Settings, custom modes, vocabulary and memory live in %APPDATA%\Waky. Your API key is in Windows Credential Manager. Uninstalling removes the app and its startup entry but keeps this data, so a reinstall picks up where you left off. Delete the folder to remove everything.
