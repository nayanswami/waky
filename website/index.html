Want to check the file first?

Open PowerShell in your Downloads folder and run Get-FileHash .\Waky-Setup.exe. The result should match the SHA-256 published with each release. The installer is per-user, so it never asks for administrator rights.

Need to change your Groq key?

  1. Open Waky Settings, then Privacy.
  2. Under Providers, set Provider to groq.
  3. Paste the new key into Groq API key and save.

Keys live in Windows Credential Manager. No reinstall needed. Get a free key →
